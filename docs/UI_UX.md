# UI/UX Notes

- Responsive founder workspace with a calm, professional style and clear left-to-right or right-to-left content direction.
- Default language is Arabic (RTL); critical labels and navigation should be available in English (LTR).
- Main areas: overview, pitch analysis, improvement suggestions, funding opportunities, startup profile, application documents, application tracking, and settings.
- Distinguish live records from illustrative/demo records in both labels and colors.
- Analysis results should expose evidence excerpts, slide/page references, severity, suggested action, and evidence status.
- Offer accept/edit/reject controls for every proposed rewrite; never silently modify the original deck/profile.
- Eligibility results show one of three states and explain each criterion. Include the official source and last checked date where available.
- Keep empty, loading, error, offline and demo states explicit; include keyboard focus, readable contrast, semantic controls, and responsive layouts.
